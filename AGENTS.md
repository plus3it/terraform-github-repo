## Repository-specific

### Purpose

This Terraform module creates a GitHub repository in an organization with the settings given by inputs such as `name`, `visibility`, and the merge options. It can also set branch protection on the repository's default branch with `branch_protection`, and grant team access with `teams`. The module outputs `repo`, which holds all attributes of the created repository.
